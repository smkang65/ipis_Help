권한설정 사용자 설명서

출판사 임직원(사용자)별로 아이피스(iPiS)의 각 업무 화면(프로그램)에 대한 접근·조회·추가·수정·삭제·관리 권한을 체계적으로 부여하고, 신규 입사자나 보직 변경자의 권한을 기존 직원과 동일하게 즉시 복사·일괄 설정하는 관리자용 업무 안내서입니다.

메뉴 위치: [관리자] > [[A0004] 권한설정] 화면 타이틀: 사용자 권한 설정 문서버전: v1.0

1. 화면 개요 및 목적

권한설정 (사용자 권한 설정) 화면은 출판사 내 부서별·담당자별 업무 분장에 맞추어 각 메뉴의 열람 및 데이터 편집 권한을 통제하기 위해 사용합니다.

💡
주요 제공 기능:
  • 3가지 관점의 입체적 권한 관리: [사용자별 권한 설정], [프로그램별 권한 설정], [전체 권한 설정] 3개 탭을 통해 사람 중심, 메뉴 중심, 전사 매트릭스 중심으로 자유롭게 전환하며 작업할 수 있습니다.
  • 6단계 세부 권한 제어: 단순 메뉴 열람(접근)부터 조회, 추가, 수정, 삭제, 관리까지 6가지 세부 권한을 개별 또는 일괄 부여/해제할 수 있습니다.
  • 원클릭 직원 권한 복사 ([권한 복사...]): 신규 입사자나 업무 인수인계 시 선임자(기준 직원)의 모든 메뉴 권한을 대상 직원에게 단 한 번의 클릭으로 똑같이 복제할 수 있습니다.
  • 시각적 권한 식별 (하늘색 강조): 권한이 부여(체크)된 항목은 연한 하늘색(LightCyan) 배경으로 자동 강조 표시되어 어떤 권한이 켜져 있는지 한눈에 파악할 수 있습니다.

2. 접속 및 메뉴 위치

1

관리자 계정 로그인

아이피스(iPiS) 실행 후 관리자 권한이 부여된 계정으로 로그인합니다.

2

메뉴 실행

상단 메인 메뉴 바에서 [관리자] > [[A0004] 권한설정]을 클릭합니다.
실행 시 상단 제목 배너에 "사용자 권한 설정" 타이틀이 표시되며, 현재 유효한 전 직원과 전체 프로그램의 권한 데이터가 자동으로 로드됩니다.

3. 6대 권한 항목 상세 안내

각 업무 화면(프로그램)마다 부여할 수 있는 6가지 권한 컬럼의 의미와 시각적 표기 규칙입니다.

권한 컬럼명 체크 시 셀 색상 권한 설명 및 제어 범위
접근 연한 하늘색 (LightCyan) 상단 메뉴 바에서 해당 메뉴를 클릭하여 화면을 열 수 있는 기본 권한입니다. 접근 권한이 해제되어 있으면 메뉴를 실행할 수 없습니다.
조회 연한 하늘색 (LightCyan) 해당 업무 화면 내에서 데이터를 검색·조회할 수 있는 권한입니다.
추가 연한 하늘색 (LightCyan) 신규 전표, 도서, 거래처, 계약 등 새로운 자료를 등록(입력)할 수 있는 권한입니다.
수정 연한 하늘색 (LightCyan) 기존에 등록된 데이터를 변경하고 저장할 수 있는 권한입니다.
삭제 연한 하늘색 (LightCyan) 기존에 등록된 자료나 전표를 삭제할 수 있는 권한입니다.
관리 연한 하늘색 (LightCyan) 마감 처리, 확정, 승인 또는 고급 관리 기능을 수행할 수 있는 관리자급 특수 권한입니다.
✨
즉시 반영 및 하늘색 하이라이트:
그리드의 체크박스를 마우스로 클릭하는 즉시 값 변경이 반영되며, 체크된 셀은 바탕색이 연한 하늘색(LightCyan)으로 바뀌어 미부여(흰색) 셀과 명확히 구분됩니다. 모든 편집을 마친 후에는 반드시 화면 우측 하단의 [저장(&S)] 버튼을 눌러야 데이터베이스에 최종 저장됩니다.

4-3. [권한 복사...] 기능 (신규 입사자·업무 인계자 빠른 설정)

우측 상단 툴바의 [권한 복사...] 버튼을 클릭하면 [사용자 권한 복사] 팝업 창이 열리며, 기존 직원이 가진 모든 메뉴 권한을 대상 직원에게 그대로 복제할 수 있습니다.

1

[권한 복사...] 버튼 클릭

[사용자별 권한 설정] 탭 우측 상단의 [권한 복사...] 버튼을 클릭합니다.

2

기준 직원 및 대상 직원 선택

• 기준 직원: 권한의 원본이 될 기존 직원을 목록에서 선택합니다. (사용자명, 아이디 표시)
• 대상 직원: 권한을 부여받을 직원을 선택합니다. (좌측 목록에서 선택해 둔 직원이 자동으로 기본 지정됩니다.)
주의 [권한 복사] 실행 시 대상 직원의 기존 메뉴 권한은 기준 직원의 권한 설정으로 모두 대체(덮어쓰기)됩니다.

3

[권한 복사(&C)] 실행 및 즉시 저장 여부 선택

하단의 [권한 복사(&C)] 버튼을 누르면 복사가 완료되며, "기준 직원 [OOO] 님의 권한 설정 N건이 대상 직원 [OOO] 님에게 복사되었습니다. 지금 변경 사항을 데이터베이스에 저장하시겠습니까?" 확인 창이 나타납니다.
• [예] 클릭: 복사된 권한이 즉시 데이터베이스에 영구 저장됩니다.
• [아니오] 클릭: 화면 그리드에만 반영된 상태로 창이 닫히며, 추가로 일부 메뉴 권한을 가감한 뒤 하단 [저장(&S)] 버튼으로 저장할 수 있습니다.

5. [프로그램별 권한 설정] 탭 상세 가이드

특정 메뉴(프로그램)를 기준으로 현재 어느 직원들에게 권한이 열려 있는지 감사(Audit)하거나, 신규 오픈된 메뉴의 권한을 여러 직원에게 한꺼번에 부여할 때 사용하는 탭입니다.

5-1. 프로그램 중심 화면 구성

• 상단 자동 필터 행에 메뉴명을 입력하여 원하는 프로그램을 빠르게 찾고 클릭하면, 우측에 전 직원의 해당 메뉴 권한 현황이 표시됩니다.

5-2. 활용 예시: 중요 메뉴(결산, 인세, 권한설정 등) 접근자 점검

보안이 중요한 메뉴(예: 권한설정, 결산재고평가 보고서 등)를 좌측에서 클릭한 뒤, 우측 그리드의 접근 컬럼 헤더를 클릭하여 정렬하거나 필터링하면 현재 해당 화면에 들어갈 수 있는 직원이 누구인지 1초 만에 파악하고 불필요한 권한을 즉시 해제할 수 있습니다.

6. [전체 권한 설정] 탭 상세 가이드

좌우 분할 없이 전 직원 × 전 프로그램의 모든 권한 매트릭스를 단일 대형 그리드에 펼쳐놓고 통합 검색·그룹핑·일괄 편집·엑셀 내보내기를 수행하는 탭입니다.

  • 기본 표시 컬럼: 사용자명, 프로그램명, 접근, 조회, 추가, 수정, 삭제, 관리 (숨김 컬럼: 아이디, 프로그램키)
  • 상단 일괄 작업 툴바: [모두 선택], [선택 반전], [선택 해제] 및 6대 권한([접근]~[관리] / 각 [해제]) 버튼을 동일하게 제공합니다.
  • 전사 권한 감사표 엑셀 출력: 그리드 좌측 상단 [▶] 메뉴 > [엑셀 형식으로 저장]을 실행하면 전 직원의 전체 메뉴 권한 현황표를 엑셀 파일 하나로 즉시 다운로드할 수 있습니다.

7. 상단 배너 및 하단 명령 버튼 안내

위치 컨트롤명 단축키 동작 설명
우측 상단 배너 [v] 툴팁 표시 - 체크 시 그리드 헤더 및 항목에 마우스를 올렸을 때 도움말 툴팁을 표시합니다. 설정 여부는 사용자 PC에 자동 저장되어 다음 실행 시에도 유지됩니다.
우측 하단 바 [저장(&S)] Alt + S 3개 탭에서 변경한 모든 권한 내역을 데이터베이스에 일괄 저장하고, "N개의 레코드가 저장되었습니다." 완료 메시지를 표시합니다.
변경된 내역이 없을 때는 "저장할 데이터가 없습니다." 안내창이 나타납니다.
우측 하단 바 [닫기(&X)] Alt + X 권한설정 화면을 닫습니다.

8. 그리드 고급 편의 기능 (좌측 상단 [▶] 단축 메뉴)

화면 내 모든 그리드의 좌측 상단에 위치한 파란색 [▶] 버튼을 클릭하면 다음과 같은 고급 레이아웃 및 데이터 내보내기 기능을 사용할 수 있습니다.

메뉴 항목명 상세 기능 설명
자동필터 그리드 최상단의 자동 필터 행(검색 입력줄)을 표시하거나 숨깁니다.
그룹패널 그리드 상단에 그룹핑 영역을 표시합니다. 컬럼 헤더를 끌어다 놓으면 사용자별 또는 프로그램별로 그룹화하여 볼 수 있습니다.
열 선택기 기본 숨김 처리된 컬럼(아이디, 프로그램키, 설명 등)을 화면에 꺼내거나 불필요한 컬럼을 숨길 수 있는 사용자 정의 창을 엽니다.
폭에 맞게 열 너비 자동 조정 그리드 전체 가로 폭에 맞추어 컬럼 너비를 자동 조절하거나 원래 너비로 전환합니다.
미리보기 컬럼 보기/숨기기 각 행 하단에 상세 설명 미리보기 영역을 표시하거나 숨깁니다.
레이아웃 저장 / 레이아웃 초기화 사용자가 조정한 열 순서, 너비, 필터 및 분할창(Splitter) 위치를 PC에 저장하거나, 최초 기본 화면 상태로 복구합니다.
인쇄 미리 보기 / 인쇄... 현재 그리드의 권한 목록을 인쇄 미리보기 창으로 확인하거나 프린터로 직접 출력합니다.
엑셀 / PDF / 이미지 / 텍스트 / RTF / HTML / MHT 형식으로 저장 현재 그리드 데이터를 원하는 문서 포맷으로 저장하고 즉시 파일을 열어 볼 수 있습니다.

9. 상황별 표준 권한 관리 절차

시나리오 A: 신규 입사자에게 같은 팀 선임자의 권한을 그대로 부여할 때

1

신규 입사자 선택 후 [권한 복사...] 클릭

[사용자별 권한 설정] 탭 좌측 목록에서 신규 입사자를 클릭한 뒤, 우측 상단의 [권한 복사...] 버튼을 클릭합니다.

2

기준 직원 지정 및 복사 실행

팝업 창의 기준 직원에서 같은 부서 선임자를 선택하고 [권한 복사(&C)]를 누른 뒤, 즉시 저장 확인 창에서 [예]를 클릭하면 5초 만에 설정이 완료됩니다.

시나리오 B: 특정 직원의 일부 업무 권한만 추가·조정할 때

1

직원 검색 및 메뉴 필터링

[사용자별 권한 설정] 탭 좌측에서 직원을 선택하고, 우측 그리드의 프로그램명 자동 필터 행에 업무 키워드(예: 인세)를 입력합니다.

2

개별 체크 또는 [모두 선택] 후 일괄 부여

해당 메뉴들의 체크박스를 직접 클릭하거나, [모두 선택] 후 상단의 [접근], [조회], [추가], [수정] 버튼을 차례로 누릅니다.

3

[저장(&S)] 클릭

우측 하단의 [저장(&S)] 버튼(Alt + S)을 눌러 변경 사항을 최종 반영합니다.

10. 자주 묻는 질문 (FAQ)

Q1. 상단 일괄 버튼([접근], [조회] 등)을 눌렀는데 "일괄적용할 행을 선택한 다음에 실행하십시오." 메시지가 뜹니다.

A: 실수로 전체 메뉴의 권한이 한꺼번에 변경되는 것을 방지하기 위해, 우측 그리드에서 선택(하이라이트)된 행에 대해서만 일괄 버튼이 작동합니다. 전체 행에 적용하려면 좌측의 [모두 선택] 버튼을 먼저 누른 뒤 권한 버튼을 클릭해 주세요.

Q2. 좌측 직원 목록에 퇴사자나 특정 계정이 보이지 않습니다.

A: 권한설정 화면은 현재 유효한 계정(사용 여부가 활성화된 직원)만 자동으로 불러옵니다. 신규 직원이 보이지 않는다면 사용자 계정 관리 화면에서 해당 직원의 계정이 등록 및 사용 활성화되어 있는지 먼저 확인해 주세요.

Q3. 직원의 아이디(ID)나 프로그램의 내부 키(코드)를 화면에서 확인하고 싶습니다.

A: 화면을 깔끔하게 유지하기 위해 아이디와 프로그램키 컬럼은 기본 숨김 처리되어 있습니다. 그리드 좌측 상단 [▶] 버튼 > [열 선택기]를 클릭하면 언제든 화면으로 끌어내어 확인할 수 있습니다.

Q4. 권한을 변경하고 저장했는데 해당 직원의 화면에 바로 적용되나요?

A: 관리자가 [저장(&S)] 버튼을 눌러 데이터베이스에 반영한 후, 해당 직원이 아이피스(iPiS)에 다시 로그인하거나 해당 메뉴를 새로 열 때 변경된 권한이 적용됩니다.
